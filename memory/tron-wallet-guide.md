# TRON 钱包设置指南 — 2 分钟搞定

大凯，你需要一个 TRON 钱包来接收 MergeOS 赏金（MRG 代币）。
选择下面任意一种方式，2 分钟搞定。

---

## 方式一：TronLink 浏览器插件（推荐，最安全）

1. 打开 Chrome 网上应用店 → 搜索 "TronLink"
2. 安装 TronLink 扩展程序
3. 点击扩展图标 → "创建钱包"
4. 设置密码（如 `Kai123!@#`）
5. **备份助记词**（抄下来或截图保存，这是唯一恢复方式）
6. 确认助记词 → 完成
7. 把钱包地址发给我（以 `T` 开头的地址）

## 方式二：Trust Wallet 手机 App（更方便）

1. 手机应用商店搜索 "Trust Wallet" 并安装
2. 创建新钱包 → 备份助记词
3. 首页 → 右上角搜索 → 添加 "TRON"
4. 你的 TRON 地址（以 `T` 开头）→ 发给我

## 方式三：OKX Web3 钱包（如果你已有 OKX 账号）

1. 打开 OKX App → 点击 "Web3 钱包"
2. 创建钱包 → 备份助记词
3. 自动支持 TRON 网络
4. 地址发给我

---

## 完成后我帮你做什么

你发我一个 TRON 地址（T 开头），我就能：
- ✅ 在 MergeOS 认领赏金任务
- ✅ 开始提交 PR 赚 MRG 代币
- ✅ 后续可以兑换或提现

## 重要提醒

- 助记词 = 你的全部资产，**别告诉任何人**（包括我）
- 不要往这个钱包里存钱，只是用来收赏金
- 整个过程免费，不需要任何个人信息
