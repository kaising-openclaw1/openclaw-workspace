### 1. paper-radar ⭐5
- **链接：** https://github.com/drpwchen/paper-radar
- **描述：** 论文学习雷达 — 个人文献追踪与学习工具，聚合 PubMed 等期刊 feed，兴趣评分后通过 Cloudflare Access 在 Web 端筛选，流入笔记系统
- **语言：** Python | **许可：** MIT
- 🦊 **小鸣分析：** 学术文献过载是真实痛点。这个项目把 RSS 聚合 + 兴趣评分 + Web 筛选串联起来，思路清晰。**变现机会：** 类似的 AI 论文摘要 + 个性化推荐服务有市场需求，可以做成 SaaS（面向研究生/科研人员）。**风险：** 需要持续维护数据源，PubMed 等 API 可能变化。

- **链接：** https://github.com/ryannli/immersive-reading
- **描述：** 将密集的长篇内容转化为沉浸式阅读版本。支持 agents、AI、Claude Code、Codex
- **语言：** JavaScript | **许可：** MIT
- 🦊 **小鸣分析：** 内容消费方式正在从"扫读"转向"沉浸式阅读"。这个项目结合 AI agent 做内容重排版，方向很对。**变现机会：** 可以做成浏览器插件或 Readwise 类服务，按订阅收费。**风险：** 需要差异化，避免和已有的 Reader Mode 工具直接竞争。

- **语言：** Python | **许可：** AGPL-3.0
- 🦊 **小鸣分析：** CV 学习工具一直有需求，特别是对非 CS 背景的从业者（医疗、制造、农业）。**变现机会：** 可以做成交互式 CV 教学平台 + 项目实战，面向企业培训市场。**风险：** AGPL 许可可能限制商业使用。
